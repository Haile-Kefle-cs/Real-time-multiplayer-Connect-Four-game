📖 How to Play

🎯 Game Goal

Connect 4 discs in a row to win!

➕ How to Create

  1. Select Create New Game
  2. Enter your name
  3. Click Create Game
  4. Share room code with friend

🚪 How to Join

  1. Select Join Existing Game
  2. Enter your name
  3. Enter 6-character room code
  4. Click Join Game

🎮 Gameplay

  1. Click column to drop disc
  2. Take turns
  3. Connect 4 to win

⏱️ Timer

10 seconds per turn

Auto-place if time runs out

💡 Tips

  • Control center
  • Block opponent
  • Watch diagonals
