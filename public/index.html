➕ How to Create a Game

  1. Enter your name in the field
  2. Click "Create Game" button
  3. Get a 6-character room code
  4. Share the code with your friend
  5. Wait for them to join
  6. You play as 🔴 Red and go first!

🚪 How to Join a Game

  1. Ask friend for room code
  2. Enter your name in the field
  3. Type the 6-character code
  4. Click "Join" button
  5. Game starts automatically!
  6. You play as 🟡 Yellow and go second!

🎮 How to Play

  1. Click on any column to drop disc
  2. Disc falls to lowest empty space
  3. Players take turns dropping discs
  4. First to connect 4 discs wins!
