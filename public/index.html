📖 How to Play

🎯 Game Goal

Connect 4 discs in a row to win!

➕ How to Create

  1. Enter your name
  2. Click Create Game
  3. Share the room code
  4. Play as Red (first)

🚪 How to Join

  1. Get room code from friend
  2. Enter your name
  3. Type the 6-character code
  4. Click Join button
  5. Play as Yellow (second)

🎮 Gameplay

  1. Click any column to drop disc
  2. Disc falls to lowest space
  3. Take turns with opponent
  4. First to connect 4 wins!

⏱️ Timer

You have 10 seconds per turn

Auto-place if time runs out

💬 Chat

Chat with opponent during game

💡 Tips

  • Control the center column
  • Block opponent's 3-in-a-row
  • Watch diagonal threats
